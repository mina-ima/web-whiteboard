web-whiteboard（リアルタイム共同ホワイトボード）取扱説明書

複数の人が同じ画面に同時に描き込めるオンラインのホワイトボードです。AIアシスタント機能も備えています。

このアプリでできること

  • ペンで自由に描画できます（線のスタイル・色を選択可能）。
  • 付箋（ステッキーノート）を貼り、内容を編集できます。
  • 画像やファイルをボードに貼り付けて共有できます。
  • 同じルームに入った複数の人と、リアルタイムで同じボードを共同編集できます（他の人のカーソルも見えます）。
  • ルームにパスコードを設定して、招待した人だけが参加できるようにできます（招待モーダル）。
  • AIサイドバー（Gemini）で、ボードに関する支援を受けられます。
  • ボード全体を画像・PDF・ZIP などで書き出し（エクスポート）できます。
  • ボードのクリア（全員に反映）ができます。

※ 同時接続できる人数の上限やデータの保存期間などの詳細は未確認です。

想定ユーザー・利用シーン

  • オンライン会議・ブレインストーミングで、複数人が同時にアイデアを書き出したいとき。
  • 遠隔の相手と図やメモを共有しながら打ち合わせをしたいとき。
  • 授業・ワークショップで参加者と画面を共有したいとき。

動作環境・前提

  • パソコン・スマートフォンのWebブラウザ（最新版 Chrome などを推奨）。
  • インターネット接続。
  • リアルタイム共同編集には、シグナリング用の WebSocket サーバー（既定で Cloudflare Workers 上）への接続が必要です。
  • AI機能の利用には Gemini API（AIプロキシ）の設定が必要です。

セットアップ

通常の利用者は、公開URLにアクセスし、名前・ルームID・パスコードを入力して参加するだけで利用できます。

開発者がローカルで動かす場合は「開発者向けメモ」を参照してください。

使い方（ステップbyステップ）

  1. アプリのURLを開くと、ログイン画面が表示されます。
  2. 表示名を入力し、ルームIDとパスコードを設定（または入力）して参加します。
    • 新しくルームを作る人は「作成者」として入り、招待モーダルが表示されます。
    • 招待された人は、共有されたルームID・パスコードで参加します。
  3. ツールバーからペン・付箋・画像/ファイル追加などのツールを選びます。
  4. ボード上に描画したり、付箋・画像を配置したりします。変更はリアルタイムで全員に反映されます。
  5. 他の参加者のカーソルや接続状況が画面に表示されます。
  6. 必要に応じてAIサイドバーを開き、支援を受けます。
  7. 作業内容は、画像・PDF・ZIP 形式でエクスポートできます。
  8. ボードを最初からやり直したいときは「クリア」を実行します（全員に反映されるため注意）。

主な機能

  • 描画ツール: ペン（スタイル選択可）、付箋、画像・ファイル添付。
  • リアルタイム共同編集: 同一ルーム内で描画・付箋・画像・カーソルを同期。
  • ルーム認証: ルームIDとパスコードで参加を制御。招待モーダルで共有。
  • AIサイドバー: Gemini を用いた支援機能。
  • エクスポート: html2canvas / jsPDF / JSZip による画像・PDF・ZIP 出力。
  • 接続状態表示: 接続中／切断、参加メンバー、認証状況をアイコンで表示。
  • ボードクリア: 全員のボードを一括クリア。

よくある質問・トラブルシューティング

  • Q. ルームに入れない／すぐにログアウトされる。 → ルームIDとパスコードが正しいか確認してください。パスコードが違うと接続エラーで戻されます。
  • Q. 相手の描画が反映されない。 → ネットワーク接続と、シグナリングサーバーへの接続状態（接続アイコン）を確認してください。
  • Q. AIサイドバーが動かない。 → AI機能には Gemini API（AIプロキシURL）の設定が必要です。VITE_AI_PROXY_URL 等の設定を確認してください。
  • Q. ボードを消してしまった。 → 「クリア」は全員に反映され、元に戻せません。実行前に確認ダイアログで内容を確認してください。
  • Q. 作業内容を保存したい。 → エクスポート（画像・PDF・ZIP）で書き出してください。
